1. Daftar konten dengan filter kanal dan halaman situs (US-1802 AC1, AC2)Kolom "Kanal" dan "Halaman situs" baru. Halaman tetap: hanya satu versi tayang per halaman, versi sebelumnya berakhir (AC2). Status memakai nada guideline §5.6 (Draf = netral, Tayang = sukses). "Tayang (terjadwal)" menandai jadwal tayang belum tiba; nama status final mengikuti PRD §3.6 [TIDAK DIKETAHUI] bila berbeda. Hapus dan pulihkan tercatat E-16.

Isi tidak dapat disimpan: HTML mentah tidak diizinkan (baris 5); tautan harus berskema https, mailto, atau relatif (baris 6); gambar harus dari pustaka gambar Ruang Sehat (baris 4); gambar tanpa teks alternatif (baris 4). Hanya Markdown. HTML mentah, skrip, dan sematan tidak didukung (US-1802 AC6).
Terisolasi (iframe sandbox tanpa allow-same-origin): skrip apa pun di pratinjau tidak dapat memakai sesi backoffice (AC8).
Teks alternatif wajib sebelum konten dapat ditayangkan.
Promo hanya informasi: tidak mengubah harga di aplikasi maupun katalog korporat (US-1802 AC3, US-1101 AC4).
!Tayangkan halaman ini?Versi yang sedang tayang untuk halaman "Tentang Kami" akan berakhir dan digantikan versi ini (US-1802 AC2).

2. Editor Markdown dan pratinjau (US-1802 AC1, AC5-AC8)Satu kolom pada < 768 px (editor di atas pratinjau). Galat per baris menjelaskan penolakan: HTML mentah, skema tautan di luar https/mailto/relatif, gambar dari luar endpoint gambar publik, gambar tanpa teks alternatif (AC5, AC6). Backend menolak atau menetralkan bagian itu; pratinjau dan situs memakai aturan render yang sama (AC7). Teks galat per field tanpa menampilkan isi berbahaya sebagai HTML (dirender sebagai teks). Pustaka Markdown dipilih di task (F1-T111). Alat bantu editor (toolbar tebal, miring) bukan bagian rancangan ini; hanya isian teks Markdown [TIDAK DIKETAHUI] apakah dibutuhkan, belum ada di PRD.
